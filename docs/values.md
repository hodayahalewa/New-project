# מאגר הערכים – טיוטה לאישור

- **אייקון** (אימוג'י זמני, שיוחלף באיור).
- **הסבר קצר:** מה שמופיע על הקלף כשהוא מתהפך.

- **אתגר שבועי:** פעולה פיזית קטנה שמממשת את הערך בעולם האמיתי.

אפשר להוסיף, להוריד, לאחד או לשנות ניסוח בכל שורה.
